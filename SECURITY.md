# Security Policy / 安全政策

## Reporting a vulnerability / 报告安全问题

Do not open a public GitHub issue. Email [support@getwingman.dev](mailto:support@getwingman.dev?subject=%5BSecurity%5D%20Wingman%20report) with a short, non-sensitive summary and steps that do not reveal private data.

请勿创建公开 GitHub Issue。请发送一份简短、非敏感的摘要至 [support@getwingman.dev](mailto:support@getwingman.dev?subject=%5BSecurity%5D%20Wingman%20report)，复现步骤中不要泄露私密数据。

In the initial report, do not attach screenshots or include prompts, logs, file paths, source code, license data, credentials, or third-party private information. We will reply from `support@getwingman.dev` if a safer follow-up is needed.

首封邮件请勿附加截图，也不要包含 prompt、日志、文件路径、源码、license 数据、凭证或第三方私人信息。如需以更安全的方式补充材料，我们会从 `support@getwingman.dev` 回复说明。

Please include:

- a concise description of the suspected impact;
- the affected Wingman version;
- minimal reproduction steps using synthetic data;
- a safe contact address for follow-up.

请提供：

- 疑似影响的简要描述；
- 受影响的 Wingman 版本；
- 仅使用合成数据的最小复现步骤；
- 可用于后续联系的安全邮箱。
