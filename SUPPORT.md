# Wingman Support / 支持

This public repository is for installer releases, release notes, and non-sensitive feature requests. It is not the intake channel for bugs, billing, or security reports.

本公开仓库用于安装包、发布说明和不含敏感信息的功能建议，不接收原始 Bug、账单或安全报告。

## Choose the right private route / 选择私密入口

| Need / 类型 | Route / 入口 |
| --- | --- |
| Bug / 产品问题 | [Private Wingman feedback form / 私密反馈表单](https://tally.so/r/aQMeVW) |
| Billing / 账单 | [support@getwingman.dev](mailto:support@getwingman.dev?subject=%5BBilling%5D%20Wingman%20support) |
| Security / 安全 | See [SECURITY.md](SECURITY.md) or email [support@getwingman.dev](mailto:support@getwingman.dev?subject=%5BSecurity%5D%20Wingman%20report) |
| Feature request / 功能建议 | [Public Feature Request form / 公开功能建议表单](https://github.com/Mich404elle/wingman-releases/issues/new?template=feature_request.yml) |

## Public privacy boundary / 公开隐私边界

Do not put screenshots, prompts, logs, file paths, source code, license data, credentials, or third-party private information in a public issue. Public issues may be visible and copied by anyone.

请勿在公开 Issue 中放入截图、prompt、日志、文件路径、源码、license 数据、凭证或第三方私人信息。公开内容可能被任何人查看或复制。

The private feedback form permits one optional screenshot only after you review and remove sensitive content. Email is the fallback if the form is unavailable.

私密反馈表单允许在你检查并移除敏感内容后，主动选择上传一张可选截图；如果表单不可用，可以改用支持邮箱。
